**类别约定**
`0=HM`、`1=LQS`、`2=QHS`、`3=MS`，这是船舶四类；`4-23` 是飞机；`24=FSC` 发射车。

**模型参数**
`variant: medium`：使用 RF-DETR Medium。容量比 small 大，适合 1024 遥感检测，但更容易在少样本类上过拟合。

`num_classes: 25`：前景类别数，不含 background。必须和数据集标签一致。

`resolution: 1024`：训练/推理输入分辨率。小目标召回依赖它。提高分辨率通常涨召回、降速度、涨显存；当前不要轻易动。

`gradient_checkpointing: true`：用计算换显存，允许 1024 + batch 16。会慢一点，但比较稳。

`pretrain_weights`：初始权重。第一步从 120ep detector baseline 启动；第二步从 E4 的 `checkpoint_best_total.pth` 启动。注意它不是 Lightning `resume`，不会恢复优化器/epoch，只是加载模型权重重新微调。

**ProtoGuidance 参数**
`proto_guidance_enabled: true`：开启多模态原型引导。它影响 encoder two-stage query selection 和 decoder content residual，是这两次实验的核心。

`proto_guidance_artifacts_path`：离线原型文件，来自 `data/proto_guidance_shwx_1024_from120ep.pt`。里面包含视觉/文本原型。路径、类别顺序、slot 数必须匹配当前 25 类。

`proto_guidance_fusion_mode: simple`：视觉原型和文本原型简单融合。`gated` 在配置里有定义，但当前主线不建议改。

`proto_guidance_num_slots: 10`：每类 10 个视觉子原型。多 slot 能覆盖多姿态/多外观。少样本类如果原型质量差，slot 多也可能带噪声；除非重建 artifact，否则不要只改这个数。

`proto_guidance_position_enabled: true`：让原型参与 encoder proposal 选点。更偏召回入口，选错会带来漏检或虚警变化。

`proto_guidance_content_enabled: true`：把原型信息注入 decoder query 内容。更偏分类边界和细粒度区分，太强可能扰动已稳定类别。

`proto_guidance_dense_loss_enabled: true`：对 encoder dense proposal token 做原型类别对齐监督。作用是让 token 更早带类别语义。

`proto_guidance_dense_loss_weight: 0.5`：dense 类别对齐损失权重。提高会加强语义对齐，可能提升召回，也可能压制原检测分布。建议调节范围 `0.25-1.0`。

`proto_guidance_dense_foreground_loss_enabled: true`：额外训练 dense token 的前景/背景判断。

`proto_guidance_dense_foreground_loss_weight: 0.75`：前景/背景 dense 损失权重。FDR 高时可上调，召回低时谨慎下调。建议范围 `0.5-1.0`。

`proto_guidance_dense_background_ratio: 1.0`：每个前景 token 采样多少背景 token。调大更压背景虚警，但可能伤召回；FSC 召回低时不建议增大。

`proto_guidance_position_score_mode: foreground_semantic`：选点分数 = 前景分数 + 语义分数。比 `margin` 更稳，比纯 `foreground` 更利用多模态语义。

`proto_guidance_position_semantic_weight: 0.25`：语义分数占比。调大更听原型，可能增强目标类但也更依赖原型质量。若 FSC 原型可靠可试 `0.35`；若船舶被误压，降到 `0.1-0.2`。

`proto_guidance_position_score_std_ratio: 0.25`：把原型分数校准到 objectness 标准差的比例。越大，原型越能改变 top-k。召回不足可小幅上调；虚警/错选上升则下调。

`proto_guidance_warmup_epochs: 2.0`：前 2 epoch 从弱引导逐步升到最大强度。续训时如果怕扰动，可设 `3-5`。

`proto_guidance_lambda_pos_init/max: 0.05 -> 1.0`：位置引导强度。`max` 越大，query selection 越受原型影响。若召回下降，优先把 `max` 降到 `0.5` 或 `0.75`。

`proto_guidance_gamma_content_init/max: 0.05 -> 1.0`：内容注入强度。若分类边界不清可提高或保持；若飞机/船舶被扰动，优先降 `gamma_content_max` 到 `0.5-0.75`。

`proto_guidance_tau_p: 0.2`：原型 cosine logits 温度。越小越尖锐，越相信最相似原型；越大越平滑。当前 `0.2` 偏稳。原型噪声大时调大到 `0.3`，想强化语义区分时调小到 `0.1-0.15`。

**训练基础参数**
`dataset_dir`：训练数据集目录。第二步仍用同一训练集。

`dataset_file: yolo`：YOLO 标注格式。

`output_dir`：输出目录。两步不同，避免覆盖。

`epochs: 20`：训练 20 轮。续训优化 FSC 建议先跑 `8-10` 轮观察，不一定跑满。

`batch_size: 16`、`grad_accum_steps: 4`：单卡有效 batch 是 `64`。更大更稳但显存/时间更高。

`lr: 1e-5`：可训练参数主学习率。第二步从 E4 续训时，如果目标是不伤船舶，建议 `5e-6` 更保守。

`lr_encoder: 1e-5`：encoder 学习率。但当前 `sscl_freeze_strategy: conservative` 会冻结 backbone/encoder，所以这个值基本不起主要作用。

`weight_decay: 1e-4`：权重衰减，常规正则。一般不动。

`clip_max_norm: 0.1`：梯度裁剪，防止 SSCL/原型损失引起梯度尖峰。建议保持。

`lr_drop: 16`：第 16 epoch 降学习率。若只跑 8-10 轮，这个不会生效。

`warmup_epochs: 0.0`：普通训练 LR 无 warmup。因为已经是续训，小 LR 下可接受。

`tensorboard: true`、`wandb: false`：日志开 TensorBoard，不开 W&B。

`device: cuda`、`devices: 1`、`num_nodes: 1`：单机单卡训练。

`resume: ""`：不从 Lightning checkpoint 恢复优化器状态。和 `pretrain_weights` 不同。

`eval_interval: 1`：每轮验证一次。适合你现在做短程调参。

`use_ema: true`：使用 EMA 权重，通常让验证更稳。最终 `checkpoint_best_total.pth` 会在 regular/EMA 中择优。

`compute_val_loss: false`：验证时不计算 val loss，只跑检测指标，省时间。

`aug_config: AERIAL`：遥感增强，实际包含水平/垂直翻转、90 度旋转、亮度对比度扰动。

`mosaic_p: 0.0`：关闭 mosaic。小目标场景下 mosaic 可能改变尺度/密度分布，当前关掉是保守选择。

`multi_scale: false`：固定 1024，不做多尺度训练。保证实验可比。

**采样与补丁**
`class_balanced_sampling: true`：启用平方根频率过采样，让含目标类的图片在 epoch 中重复出现。

第一步 `class_balanced_class_ids: [0, 1]`：重点过采样 HM/LQS，服务船舶小样本。

第二步 `class_balanced_class_ids: [0, 1, 24]`：加入 FSC，让发射车图片更多出现。但这仍会继续照顾 HM/LQS，所以不是纯 FSC 训练。若只想定向 FSC，可改成 `[24]`。

第二步 `patch_paste_enabled: false`：补丁粘贴总开关，当前关闭，所以后面 patch 参数全部不生效。

`patch_paste_dir: data/fsc_patch_pool`：FSC 正/负补丁池位置。只有开启 patch paste 才读取。

`patch_paste_prob: 0.5`：触发概率。FSC 召回低可以开 `0.25-0.5`；怕分布漂移先用 `0.25`。

`patch_paste_max_patches: 2`：每图最多贴 2 个。保守建议先设 `1`。

`patch_paste_target_classes: [24]`：只贴到本来就含 FSC 的图，避免把发射车贴进不合理背景。

`patch_paste_neg_ratio: 0.5`：正负补丁各半。FDR 高就提高负样本比例；召回低就降低到 `0.25-0.4`。

**SSCL 参数**
`sscl_enabled: true`：开启语义相似度监督对比学习。它作用在 Hungarian matched decoder query feature 上。

`sscl_semantic_matrix_path`：CLIP 文本语义矩阵。用于决定哪些类别负样本更需要拉开。

`sscl_matrix_normalize: minmax`：把语义相似度归一化到 `[0,1]`，增强易混类别差异。建议保持。

`sscl_lambda: 0.02`：SSCL 损失权重。越大，特征空间类别分离越强，也越可能伤原检测能力。建议范围 `0.01-0.03`。

`sscl_tau: 0.1`：对比学习温度。越小越强硬。若召回被压，调到 `0.15-0.2`；若类别混淆严重，保持或降到 `0.07`。

`sscl_rho: 0.3`：语义相似负样本的放大系数。越大越拉开易混类。船舶混淆高可上调，稳定性差则下调。

`sscl_omega_max: 2.0`：负样本权重上限，防止语义权重过大。一般不动。

`sscl_anchor_classes: [0,1,2,3]`：只有船舶四类作为 SSCL anchor。关键点：第二步虽然 hard-neg 只压 FSC，但普通 SSCL 仍在优化船舶，不优化 FSC。若想 FSC 也参与 SSCL，需要把 `24` 加进 anchor，但风险是 FSC 样本少、容易不稳定。

`sscl_confusing_classes: [0,1,2,3]`：只对船舶类负样本施加语义放大。FSC 目前不在普通 SSCL 的 confusing 集里。

`sscl_start_epoch: 0`：从第 0 轮开始启用 SSCL。第二步若怕扰动船舶，可把它设大，比如 `100`，等于本轮关闭普通 SSCL。

`sscl_freeze_strategy: conservative`：冻结 backbone、encoder、bbox head、早期 decoder，只解冻末尾 decoder、norm、class head 和 ProtoGuidance 附加模块。适合已收敛模型续训。

`sscl_unfreeze_decoder_layers: 2`：解冻最后 2 层 decoder。越大适应能力越强，也越容易遗忘。保护船舶/飞机时可试 `1`。

`sscl_prototype_enabled: false`：不用 SSCL EMA 视觉原型库，当前是 instance-to-instance SSCL。少样本 FSC 下开启原型不是第一优先，因为会引入新的不稳定因素。

**Hard Negative 参数**
`sscl_hard_neg_enabled: true`：对高分但未匹配 GT 的 query 施加前景 logit 抑制，降低虚警。

`sscl_hard_neg_topk: 5`：每图最多选 5 个难负样本。FDR 高可增，召回掉则减到 `2-3`。

`sscl_hard_neg_score_thresh: -0.7`：候选难负样本的 logit 下限。越低候选越多、更激进；越高越只压高置信虚警。召回受伤时建议提高到 `-0.3` 或 `0.0`。

`sscl_hard_neg_log_interval: 100`：每 100 step 记录一次 hard-neg 诊断。

第一步 `sscl_hard_neg_target_classes: [0,1,2]`：只压 HM/LQS/QHS，不压 MS，也不压 FSC。对应 E4 船舶 FDR 下降。

第二步 `sscl_hard_neg_target_classes: [24]`：只压 FSC 虚警。这是“尽量不影响船舶”的关键改动。

`sscl_hard_neg_iou_low: 0.0`、`iou_high: 0.15`：只把和任意 GT IoU 在 `[0,0.15]` 的未匹配 query 当难负样本。`iou_high` 越高，越可能误压定位偏差的真阳；FSC 召回低时不要升高。

`sscl_hard_neg_loss_lambda: 0.3`：hard-neg 损失全局权重。源码里还会作为 `weight_dict` 再乘一次，所以它影响很明显。

`sscl_hard_neg_logit_margin: -1.5`：目标类别 logit 的软上界。高于这个值就被压。数值越接近 0，越宽松；越负，越强硬。注意第二步 FSC 被单独覆盖成 `-2.5`，更强硬的上界，但又配合较小类内 lambda。

`sscl_hard_neg_target_logit_margins: {24: -2.5}`：FSC 专属 margin。若 FSC recall 继续下降，把它放宽到 `-2.0` 或 `-1.5`；若 FSC FDR 仍高，可保持 `-2.5`。

`sscl_hard_neg_target_loss_lambdas: {24: 0.15}`：FSC 单样本抑制系数。实际 hard-neg 总强度约受 `0.3 * 0.15` 影响。召回低就降到 `0.05-0.1`；FDR 高就升到 `0.2`。

`sscl_hard_neg_logit_temperature: 1.0`：softplus 平滑温度。越小越像硬阈值，越大越平滑。一般不动。

`sscl_hard_neg_proto_lambda: 0.05`：难负样本远离前景原型的辅助项。当前 `sscl_prototype_enabled=false`，默认 `proto_source=sscl` 时通常没有有效 SSCL 原型，因此这项大概率贡献很小或为 0。若想用 ProtoGuidance 原型排斥，要显式设 `sscl_hard_neg_proto_source: proto_guidance`。

`sscl_hard_neg_proto_margin: 0.1`、`proto_temperature: 0.1`：控制原型排斥的阈值和平滑程度。当前不是优先调参点。
