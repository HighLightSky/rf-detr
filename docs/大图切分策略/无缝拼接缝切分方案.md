# 无缝拼接缝切分方案（里程碑 4）

- 方案日期：2026-08-14
- 状态：已确认立项（比赛图 = 小图行式无缝拼接，目标不跨缝；无道路等长直线干扰）
- 对比基线：`output/0813-强基线-多原型/0813-SHWX-SSCL-MultiProto-HardNegSuppress-v5-强基线-1024-强SSCL-MS不负样本抑制`
- 相关实验目录：`output/0813-强基线-多原型/…-eval-large-seam`（新）

## 1. 背景与动机

里程碑 1–3（滑窗切分 + nms/center/center_rescue 合并）解决了大图"能否推理"的问题，
但虚警率一直明显高于无大图时的小图评测（小图 FDR=0.093，大图 center=0.1436，nms=0.2292），
根因（见《大图切分策略梳理与虚警分析》）主要是：

1. **视图基数放大**：100 张大图 → 8080 个滑窗块（平均 80.8 块/张），每块约 0.5 FP 的固有率
   不变，FP 绝对数线性放大 12 倍；
2. **切块截断**：目标跨块边界被切开 → 残框与 GT IoU 不足 → 结构性虚警/漏检；
3. **重叠重复检测**：overlap=256 引入跨块重复预测，合并策略只能压掉一部分。

**已确认的关键事实**：比赛大图就是**小图行式无缝拼接**而成（每行内部的小图边界各行不同，
目标框完整落在单个小图内、不跨拼接缝；每张小图一般不超过 1200px），且图像中没有道路等
长直线干扰。

**核心思路**：不再用固定滑窗，而是**检测小图拼接缝，沿缝切割**：

- 沿缝切割 → 图块 = 源小图 → 目标**天然不被截断**（目标不跨缝）；
- 图块之间无重叠 → **无重复检测**、无需 overlap、无需 NMS/center 合并；
- 图块 ≤1024 直接整块缩放 1024 推理（与全小图基线路径同构）→ 指标应回到全小图基线水平
  （FP≈341，FDR≈0.093）。

## 2. 缝检测算法（统计断点，无模型）

拼接缝的两类可观测特征（基于 hstrip 实测）：

| 特征 | 信号强度 | 说明 |
|---|---|---|
| 辐射跳变 | 弱 | 相邻源图亮度/色调差被 JPEG 平滑，列梯度中位数基线 25、缝处仅 2x 左右 |
| 内容切换 | 强 | 缝两侧来自不同源图，相邻列相关性骤降（实测可到负相关），条带直方图距离大 |

检测流程（全部 numpy 操作，全分辨率执行，无对齐误差）：

```
1. 灰度化 → 行/列间差分矩阵（uint8 减法）
2. 水平缝（全宽行边界）：
   - 行差分剖面 diff[y, x] = |g[y,x] - g[y-1,x]|（黑区像素对排除）
   - 跳变阈值 thr = 图像中位数差分 × 2.0
   - 一致性 voting：consist[y] = 该行差分 > thr 的列占比（缝行在整行上持续跳变）
   - 候选：consist[y] > 0.5 且平均跳变 > 中位数 × 1.5 → 近邻合并（间距 < 8px 取最强）
3. 行条带 = 相邻水平缝之间的区间；每条带内检测垂直缝（同一算法转置，
   一致性按"该列在条带内的行占比"计算）——垂直缝按条带独立检测，
   因为每行的拼接边界位置互不相同（这是与"全高垂直线"方案的本质差异）
4. 图块组合 = 条带 × 列区间，坐标回全图
5. 兜底：图块任一边 > 1200px（缝检测漏缝时可能跨两个源图）→ 图块内部退回
   滑窗网格（overlap=256 + center 合并，复用里程碑 2 机制）
```

## 3. 推理与合并

- 图块 ≤ 1024 → 整块缩放 1024×1024 推理，`target_sizes` 按图块内容尺寸映射坐标
  （与全小图基线路径同构，语义一致）；
- 图块 1024–1200 → 直接缩放 1024（已确认：图块一般 ≤1200，最大 1.17x 缩小，可接受）；
- 图块 > 1200 → 滑窗兜底（漏缝保护）；
- 合并策略固定 center（无重叠时重复检测几乎不存在，center 仅为预测噪声兜底，
  IoU>0.9 级安全合并不误伤相邻目标）。

## 6. 验证方案

1. **单元测试**（`tests/scripts/test_seam_cut.py`）：合成拼接图（随机纹理块拼接，已知缝位置）
   检测准确性；无拼接图不误检；黑底/条带兜底等边界情况；
2. **真实数据调参**：`make_hstrip_test.py` 是确定性生成（SEED=42 + 画布 ID 派生随机源），
   重放 `make_canvas` 的摆放逻辑可拿到**每张画的真实拼接位置**作为 ground truth →
   统计缝检测的 precision/recall；
3. **安全性验证**：检测出的切割线不得穿过任何 GT 框（大图 GT 由脚本精确换算，
   目标不跨缝，故真缝必然安全；切割线穿框 = 检测错误）；
4. **指标对比**（同一 checkpoint，772 张全量评测）：
   - 期望：整体指标 ≈ 全小图基线（FP≈341，FDR≈0.0931，Recall≈0.969）；
   - 对照：eval-large center（FP=4245，FDR=0.1436）——缝切分应显著优于滑窗。

## 8. 已知限制与后续

- 缝检测依赖拼接缝的内容切换/辐射跳变信号；若相邻源图视觉上几乎相同（同 CCD 相邻条带），
  漏缝风险存在 → 漏缝图块 >1200 时滑窗兜底，指标影响可控；
- 本方案针对"行式无缝拼接"结构；若比赛图是任意 mosaic（如 concat 版），缝不是直线，
  需要"安全切割线"泛化方案（见《大图切分策略梳理与虚警分析》方向六）；
- 后续可加：双边条带直方图确认（滤长直线干扰，当前比赛图无此干扰故未启用）、
  缝检测并行化。
