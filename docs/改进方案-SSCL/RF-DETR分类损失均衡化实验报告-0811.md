## 4. 核心结论

1. **灰度增广（RGB→灰度复制 HM/LQS）是召回与虚警变化的唯一主导因素**：
    - 召回升（0.8759→0.9081）：HM/LQS 样本量 6/15→58/85（约 9×/5.7×），FN 归零；
    - 虚警升（HM FP 7→20、LQS 6→10）：**无 P0 时灰度增广单独就制造了大部分新虚警**。
2. **P0 正样本类均衡在本轮无增益**：原因有二——(a) 权重基于增广后 counts（w_HM≈1.56 温和）；
    (b) 增广已经解决了"HM/LQS 训练不足"，损失侧再补的边际 ≈ 0。
3. **灰度增广存在类别-灰度泄漏**：89% 的 HM 图是灰度，飞机类全 RGB → 模型学到
    "低饱和度≈HM/LQS"，测试 RGB 图中的海洋/阴影/暗区背景被触发（56% 纯背景虚警）。
4. **宏平均门槛仍未达成**：校准后最高在 0.79@0.195 或 0.85@0.27 之间，缺的那部分是
    ship 类 TP/FP 分数重叠（尤其 MS 低分 TP 多）。

## 5. 下一步建议（按优先级）

1. **修复灰度泄漏**（低成本、收益明确）：改为**随机灰度化**（HM/LQS 每图 50% 概率转灰度，
    保留 RGB 原图）或**全局灰度增广**（所有类别统一），消除"灰度=HM/LQS"相关性后再重训一版
    与无均衡-E0 对比——预期召回保持、虚警下降。
2. **虚警侧**：纯背景虚警 56% → 叠加 sscl_hard_neg（前景-背景边界难例负样本）或
    QNorm-Obj 物体性门控（仓库已有机制）。
3. **P0/P1 暂缓**：本数据集上无增益证据；若修复灰度后 HM/LQS 仍检出不足，再考虑
    （届时基于**未增广 counts** 计算权重，w_HM≈1.8 而非 1.56）。
4. 每轮训练后保持阈值重标定流程（校准脚本已就绪）。
